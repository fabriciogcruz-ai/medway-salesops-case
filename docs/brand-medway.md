# Identidade visual observada — Medway

**Fonte primária:** https://www.medway.com.br/ — inspecionada em 18/10/2026 no navegador, incluindo CSS computado e SVG do logotipo no cabeçalho.

- **Logo:** `public/medway-logo.svg` é a marca vetorial presente no elemento `#medway-logo svg` do site, extraída sem redesenho. Cores internas do SVG: azul `#00205B`, verde-água `#01CFB5`. Uso neste case apenas como contexto de apresentação à própria Medway; não declarar endosso oficial.
- **Azul principal:** `#00205B` (rgb 0,32,91), usado em textos e marca.
- **Verde-água:** `#01CFB5` na marca; botões observados em `rgb(1,195,170)` (`#01C3AA`).
- **Tipografia:** cabeçalhos e navegação em Montserrat (Next.js `__Montserrat_171594`), com peso 600–700; fontes adicionais Lato no site. O dashboard prioriza Montserrat para títulos e interface.
- **Padrão visual:** superfície branca, azul-marinho profundo, verde-água como acento, botões arredondados; hero azul com variação para ciano. Não usar a paleta creme/sálvia/coral nem a serifada do primeiro protótipo.

**Nota técnica:** os arquivos Montserrat em `assets/fonts/` foram baixados da distribuição Google Fonts e incluem `OFL.txt`. O site público pode usar a fonte web do Google; o PPTX referencia Montserrat instalada no Mac do candidato para renderização fiel.
