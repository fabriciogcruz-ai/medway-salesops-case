NOTAS DE LEITURA / 01—04

Antes de tomar
uma decisão.

O rigor importa tanto quanto o gráfico. Estas são as fronteiras do que os dados permitem afirmar.

Ver fontes, regras e limites +
01 / ORIGEM

B2C vem de um CSV fechado fornecido para o case; não há conexão à planilha viva. B2B usa a API quando disponível no servidor e um snapshot datado como contingência. No GitHub Pages, a coleta é agendada; o horário exibido é da coleta, não da última alteração na origem.

02 / DEFINIÇÕES

B2C soma valor_pago por data da venda, incluindo zeros e ajustes negativos. B2B soma valor_mensal apenas dos contratos cujo status atual é ativo. Valor contratado não é recebimento.

03 / COMPARAÇÃO

Vendas acumuladas e valor mensal contratado não formam uma “receita total”. Sem histórico de status, datas de encerramento e regras de cobrança, não é possível reconstruir MRR passado ou churn por período.

04 / QUALIDADE

Formatos de data e moeda foram normalizados. Linhas idênticas permanecem sem ID transacional para deduplicação segura. Um pico diário expressivo é destacado, não atribuído a uma causa sem evidência.
